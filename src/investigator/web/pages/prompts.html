The agents' prompts

Every agent is one call to Claude (Haiku) with a fixed instruction, shown here exactly as the system uses it. The agent must answer in the JSON format below it; an answer that does not fit is sent back with the problem (at most 3 attempts). No prompt mentions any test case, service or answer: a test checks that.

Each call's message also contains the incident brief, the blackboard so far and the agent's tool results; open a case and use the walk-through to see the exact message for every step.
